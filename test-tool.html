Understanding Your Test Results

🎯 Refresh Rate Analysis

Your monitor's refresh rate determines how many times per second the display updates. Our advanced testing uses three detection methods:

  • Browser API Detection: Queries system-reported refresh rates
  • Frame Timing Analysis: Measures actual frame delivery intervals
  • Animation Sampling: Uses requestAnimationFrame for precise timing

The tool takes 120+ samples and uses statistical analysis to determine the most accurate refresh rate measurement.

⚡ Frame Time Consistency

Frame time consistency measures how evenly frames are delivered. Perfect consistency means:

  • Each frame takes exactly the same time to render
  • No stuttering or micro-stutter in animations
  • Smooth motion without visual artifacts
  • Optimal gaming and viewing experience

Our consistency score rates from 0-100%, with 95%+ considered excellent for professional use.

🎮 Input Latency Testing

Input latency is the total delay from input to visual response. Our test measures:

  • Display Latency: Time for pixels to change state
  • Processing Delay: Graphics pipeline latency
  • System Latency: Overall input-to-photon delay

Lower latency provides better responsiveness, especially crucial for competitive gaming.

📊 Performance Benchmarks

Our quality indicators are based on professional testing standards:

  • Excellent (90-100%): Professional gaming grade, 144Hz+, <5ms latency
  • Good (70-89%): Enthusiast grade, 75Hz+, <10ms latency
  • Average (50-69%): Standard use, 60Hz, <20ms latency
  • Poor (<50%): May need hardware upgrade or optimization
